# JamesAgent 马来西亚 iGaming 代理版 0.3.2

本次只提供 Apple 芯片 Mac 安装包，要求 macOS 14 或更新版本。

- 聊天新增“清空对话”和“清除记忆”。清空对话保留备忘录；清除当前 AI 记忆同时清空它的对话和专属备忘录。
- 记忆中心可清除全部 AI 的对话与备忘录，包括共享备忘录。操作前会说明范围并要求确认。
- 清除后，已在生成的旧聊天回复不会重新写回对话或添加备忘录。采集任务、画像、线索、来源池、学习样本、提示词修改和账号配置保留。
- 更新默认聊天提示词和软件功能说明，支持没有历史任务时回答配置与业务研究规划问题；缺少必要信息时先澄清。
- 修正专用版画像生成的市场标签提示词，使它与代理线索采集规则一致。

升级时退出旧应用，将新应用拖到“应用程序”替换旧应用。使用同一专用版的数据目录，已有配置保留。

客户自行修改过的提示词仍优先使用。如需要新默认聊天提示词，可在“AI 记忆 → 提示词”找到 `chat.system` 并恢复默认。清除对话与备忘录不会恢复自定义提示词。

安装包使用临时签名，未做 Apple 公证；如系统阻止打开，可在“系统设置 → 隐私与安全性”允许打开。
